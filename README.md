# Тестовое задание Агроноут

## Требования

- Python 3.11+
- Зависимости указаны в файле `requirements.txt`

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd phone-extractor
```

2. Создайте и активируйте виртуальное окружение

Linux:

```bash
python -m venv venv
source venv/bin/activate  # В Windows: venv\Scripts\activate
```

Windows:

```bash
python -m venv venv
source venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск программы:
```bash
python3 main.py
```

Программа предложит:
1. Ввести путь к файлу для обработки
2. Или нажать Enter для использования тестового файла (test_data.txt)

Результаты будут сохранены в файл `result.txt` в той же директории, что и исходный файл.


### Поддерживаемые форматы телефонных номеров

Извлекатель поддерживает различные форматы телефонных номеров:
- `+7 912-345-67-89`
- `8 (495) 123 45 67`
- `+7(903) 456 78 90`
- `8-900-111-22-33`
- `+7-900-123-45-67`
- `+7 (999) 888.77.66`

Все номера нормализуются к формату: `+7(YYY)XXX-XX-XX`

## Тестирование

Запустите тесты:
```bash
pytest test_phone_extractor.py -v
```

## Структура проекта

- `phone_extractor.py` - основной модуль для извлечения номеров
- `main.py` - консольный интерфейс для удобного использования
- `test_phone_extractor.py` - модульные тесты
- `test_data.txt` - тестовый файл с примерами номеров
- `requirements.txt` - зависимости проекта
